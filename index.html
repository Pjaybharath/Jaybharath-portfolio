Offense informs defense

I started in a SOC triaging alerts, moved to penetration testing, and now split my time between attacking systems and building the detections that watch them. Knowing how an intrusion actually unfolds makes both sides better.

My work is practical: web and API testing, Active Directory attack paths, cloud misconfigurations, and detection rules that analysts trust because they fire rarely and mean something.

Outside work I run CTF teams, write up what I learn, and teach junior analysts how to read an attack timeline.
